Riverbend Yoga Studio - Touchstone 4
Student: Edicel Nuviola

This is the same four-page Riverbend Yoga Studio website from Touchstone 3,
with JavaScript added to services.html and events.html. Keep the entire folder
together in your IDE, including media, styles.css, and script.js.

Preview: open index.html in the IDE preview and copy the public working URL
into the implementation explanation document. Do not use a local file URL as
an external preview link.

Test the feature:
1. Open services.html. Choose Gentle Yoga, Vinyasa Flow, or Restorative Yoga.
   The details and selected button change immediately.
2. Reload services.html. Your chosen class should still be selected.
3. Open events.html. The selected class should be preselected in the form.
4. Select an experience level, reload, and confirm it is retained.
5. Submit a short name, malformed email, and short message. Errors should
   appear beside the fields without clearing entered information.
6. Correct the errors and choose a contact method. The successful demo
   message should state that nothing was sent or reserved.

The site is a demonstration. The form does not submit to a server. Use sample
information only. Preferences are stored on the device in localStorage.

Media came from the earlier Sophia Learning project. The site retains its
prior HTML pages, CSS layout, navigation, image, and audio.
